
# Buscador de países

Proyecto de Programación Web.

## Descripción
Página web que permite buscar países mediante una API REST.

## Funciones
- Buscar países por nombre.
- Filtrar países por región.
- Ordenar por población.
- Consultar idiomas y monedas.
- Mostrar bandera, capital y población.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- API REST Countries
